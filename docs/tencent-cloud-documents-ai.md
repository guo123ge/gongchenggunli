# 腾讯云部署与资料/AI 能力说明

## 当前已实现

- 文件默认保存到服务器本地 `uploads/` 目录。
- 上传接口返回 `/api/upload/[fileName]`，手机端和电脑端都通过同一域名访问。
- 上传资料可自动登记到“资料库”，记录项目、模块、提交人、角色、文件地址、AI 审查状态、资料来源类型。
- 施工日志、材料入库、安全隐患、档案上传这几条主路径，图片都会自动进入资料库。
- 语音录制后会自动上传音频文件到资料库，再进行转写。
- 智能助手支持规范咨询、拍照/图片提问、语音提问、资料审查的前端与接口基础。
- 资料库页面支持直接发起“AI 审查”，审查结果会回写到资料记录。

## 腾讯云轻量服务器建议

- 将项目部署在腾讯云轻量应用服务器。
- 将 `UPLOAD_DIR` 指向持久化目录，例如 `/data/construction/uploads`。
- 使用 Nginx 反向代理 `http://127.0.0.1:3000`。
- 域名备案通过后，将 `guo123guo.cn` 解析到轻量服务器公网 IP，并配置 HTTPS。

## 腾讯云 COS 预留配置

项目已经预留以下环境变量：

- `TENCENT_COS_REGION`
- `TENCENT_COS_BUCKET`
- `TENCENT_COS_SECRET_ID`
- `TENCENT_COS_SECRET_KEY`
- `TENCENT_COS_PUBLIC_BASE_URL`

当前版本仍以本地 `uploads/` 为主存储。后续接入腾讯云 COS 时，建议：

1. 保留现有 `/api/upload` 接口不变。
2. 在接口内部把本地写文件替换为 COS 上传。
3. 上传成功后继续返回统一的资料记录结构。
4. `storageProvider` 自动切换为 `tencent-cos`。

这样前端页面、资料库、智能助手都无需大改。

## 后续正式增强建议

- 行业规范问答建议接入企业规范 PDF/Word 知识库，建立向量检索。
- 材料市场价格建议接入造价信息网、供应商报价库或第三方价格 API。
- 图片安全检查和材料识别建议配置真实视觉模型服务。
- 语音问答建议配置正式语音转写服务，并把原始语音长期保存到 COS。
- 资料库建议增加筛选、审批流、版本管理、下载日志和权限水印。
