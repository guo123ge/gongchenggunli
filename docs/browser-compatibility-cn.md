# 大陆浏览器兼容验收清单

## 目标浏览器

- 手机端：微信内置浏览器、QQ 浏览器、华为浏览器、夸克、UC、360 手机浏览器
- 电脑端：Chrome、Edge、360 安全浏览器、QQ 浏览器

## 核心验收项

1. 登录页可正常打开，账号密码登录成功。  
2. 登录后回调到 `/dashboard` 正常。  
3. 会话保持正常（刷新后不丢失）。  
4. 上传图片/附件成功，能正常预览或下载。  
5. 施工日志、材料、安全、档案、变更签证、审核中心可访问。  
6. AI 功能不可用时有中文回退提示。  
7. 无英文用户可见文案残留。  

## 建议执行方式

- 每个浏览器至少执行 1 次完整流程：
  - 登录 -> 新建日志 -> 提交材料记录 -> 查看审核 -> 上传附件
- 在移动、联通、电信三网各抽样 1 次。
