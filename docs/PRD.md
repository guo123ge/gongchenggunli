# 施工现场综合管理平台 PRD 摘要

本项目根据 `2026-05-31_construction-site-platform-build-plan.md` 创建，目标是面向施工单位提供施工日志、材料、机械、安全、档案、变更签证六大模块，并支持多角色协同、审核流和 PWA 离线。

## Phase 1 MVP

- 用户与角色：PM、施工员、技术、安全、材料、资料、机械管理员。
- 施工日志：列表、新建、详情、模板、照片水印、语音入口、草稿自动保存。
- 材料管理：库存看板、入库、出库、库存预警和审核流。
- 首页仪表盘：待审、逾期、安全隐患、低库存、保养到期。
- 审核中心：统一通过、驳回、退回修改。
- 离线能力：Dexie 草稿表和同步队列。

## Phase 2/3 扩展

- 安全隐患、机械、档案、变更签证页面骨架已创建。
- AI OCR、风险识别、语音转写 API 以可替换服务层占位。
