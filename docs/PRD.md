# 施工现场综合管理平台 PRD 摘要

本项目基于 `2026-05-31_construction-site-platform-build-plan.md` 实施，目标是为施工单位提供施工日志、材料、机械、安全、档案、变更签证六大模块，并支持多角色协同、审核流和跨端使用。

## 当前范围

- 用户与角色：PM、CON、TECH、SAFE、MAT、DOC、MACH（界面中文展示分别为：项目经理、施工员、技术负责人、安全员、材料员、资料员、机械管理员）。
- 施工日志：列表、新建、详情、模板、图片水印、语音转写、草稿自动保存。
- 材料管理：库存看板、入库、出库、库存预警、审核流。
- 安全管理：隐患上报、整改流、检查表、风险热力图、事件上报与跟踪。
- 档案管理：档案列表、文件上传、版本记录、在线预览提示。
- 变更签证：变更记录、签证记录、工程量台账、费用汇总。
- 审核中心：统一通过、驳回、退回修改。
- 离线能力：Dexie 草稿与同步队列。

## 部署策略（双活）

- 轨道 A：Vercel 外链（快速发布、备用入口）。
- 轨道 B：国内正式域名（备案 + HTTPS，主用入口）。
- 两轨同版本代码、同一数据库策略、同一账号体系。
- 统一登录入口：`/login?callbackUrl=%2Fdashboard`。

## 文案与账号标准

- 全部用户可见文案保持中文。
- 对外账号清单按“账号 + 中文角色名 + 职责”发布。
- 默认密码与重置流程由项目管理员统一管理并可在审核中心追踪。
